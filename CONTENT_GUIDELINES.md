# Content Guidelines

## Principles

- Write for customers first in natural Indian English
- Use honest service-area wording: “service available in”, never “our branch in” unless verified
- Do not invent population, weather, landmark or review data
- Do not use city-name-only or service-name-only spinning

## Length Targets

| Page type | Useful words |
|-----------|--------------|
| Homepage | 2,500–4,000 |
| Service | 2,000–3,500 |
| City / district | 1,500–2,500 |
| City-service | 1,500–2,500 |
| Area | 1,000–1,800 |
| Area-service | 1,200–2,000 |
| Property-type / solution | 1,200–2,000 |
| Guide | 2,000–4,000 |
| Blog | 1,500–3,000 |
| About | 1,200–2,000 |
| FAQ / pricing / materials / safety | 1,500–3,500 |

Shorter useful pages beat longer filler. Content is assembled from `src/data/service-page-content.ts`, `service-faqs.ts`, `location-page-content.ts` and `static-page-content.ts`.

## Pricing Statement

Use only:

> Pricing depends on measurements, material grade, required spacing, installation complexity, building height, site accessibility and total project quantity.

## Uniqueness

Meaningful uniqueness requires different intent, verified local facts, property needs, problems or installation guidance — not adjective swaps or section reordering.
